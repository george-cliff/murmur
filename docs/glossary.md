# Murmur glossary

> [!WARNING]
> **Transparency:** this document was generated by AI and will be replaced with a human-written version soon.

| Term | Definition | Status |
| :-- | :-- | :-- |
| **Murmur** | The bioacoustics project and the proposed ecosystem as a whole; the name is shortened from “murmuration”, a flock of starlings | Active project |
| **Sparrowhawk** | Murmur's PyTorch convolutional model for binary bird/not-bird classification; it gates the more expensive species model | Implemented in Python and the Rust desktop pipeline |
| **Perch** | Google's Perch v2 bioacoustics model, consumed as ONNX with a label list to return species predictions | Implemented in the Rust desktop pipeline |
| **Starling** | The proposed field device that would capture audio and run local inference | Planned; hardware not confirmed |
| **Tern** | The proposed low-power radio gateway between field devices and the home-server side | Planned |
| **Nest** | The proposed home-server service that would receive and store detections | Planned |
| **Roost** | The proposed dashboard for detections, activity, history, and device state | Planned |
| **Inference** | Running a trained model on new input to produce a score or prediction | Implemented for development WAV files |
| **ONNX** | Open model format used to move Sparrowhawk from PyTorch training into ONNX Runtime and to consume Perch | Implemented |
| **ONNX Runtime** | Runtime used by Python validation and the Rust desktop proof of concept to execute ONNX models | Implemented |
| **Logit** | Raw model output before the sigmoid conversion used by the current binary decision and score handling | Implemented model interface |
| **Deployment threshold** | Saved Sparrowhawk probability cut-off above which the application treats a clip as containing a bird call | Implemented; final value still under review |
| **Mel spectrogram** | Time–frequency representation of audio using mel-scaled frequency bins; Sparrowhawk consumes a log-scaled 128-bin version | Implemented in Python and Rust |
| **QDQ quantisation** | Static INT8 quantisation format using explicit Quantise/Dequantise operations in the ONNX graph | Implemented in the Python pipeline |
| **DCASE 2018 datasets** | [`freefield1010` (`ff1010bird`), `warblrb10k`, and `BirdVox-DCASE-20k`](https://dcase.community/challenge2018/task-bird-audio-detection), used by Murmur's preprocessing and cross-dataset fold design | Implemented training input; raw and processed dataset files excluded from Git |
| **LoRa** | Low-power long-range radio technology being considered for sending small detection messages | Planned option |
| **LoRaWAN** | Network protocol built around LoRa radios; one of the options being considered for the link between field devices and the proposed Tern gateway | Option under consideration; not decided |
| **Unit** | A recording/inference device identity in the SQLite schema | Example desktop unit implemented; field units planned |
| **Deployment** | A period in which a unit is associated with a location and operating context | Database support implemented; field deployment planned |
| **Detection sequence number** | Per-unit sequence used by the desktop runner to avoid inserting the same development detection twice | Implemented |
| **Environmental context** | Weather, air quality, and moon-phase information intended to accompany detections | Retrieval implemented; database link incomplete |

See [Architecture](architecture.md) for how the named components relate, and [Roadmap](roadmap.md) for their implementation status.
